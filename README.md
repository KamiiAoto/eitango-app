# 英単語カードアプリ（eitango）

受講番号：6th-18
氏名：神井碧斗

## 1. プロダクトの紹介

単語帳を撮影した画像から，OCRで英単語と日本語訳を読み取ってカードとして保存し，Ankiに取り込んで学習できるWebアプリです．

今回の提出版は，開発期間を踏まえ，「画像の読み取り → 候補の確認・修正 → 保存 → Ankiへの出力」という一連の流れを完成させることに絞った最小構成です．OCRは所定の配置で切り出した英単語と訳の1組を対象とし，今後は撮影・読み取り範囲・Anki連携を段階的に拡張する予定です．

- 画像から英単語・訳を読み取り，候補として表示する（Tesseract.js，ブラウザ内で処理）
- 候補を元画像と見比べて修正し，選んだものだけをデッキにまとめて保存する
- 同じデッキに同じ英単語・訳のカードは重複して登録されない
- デッキのカードをAnki用ファイルに出力できる．アプリで編集したあと再出力し，Ankiに再取り込みすると，Anki側のカードも更新される
- デッキ・カードの作成／編集／削除，カードの検索・ページ分割

**この題材を選んだ理由**

英語の資格試験に向けて，Ankiで単語の復習をしています．しかし，単語カードの作成に手間がかかり，学習効率が大きく落ちていました．
Ankiは所定の形式のファイルを読み込むと，単語をまとめて登録できます．ただ，これまでの手順は次のように多く，これすら面倒になってAnkiをあまり活用できなくなっていました．

1. 単語帳の写真を撮る
2. 生成AI（ChatGPTなど）に写真を送り，.txtファイルを作らせる
3. .txtファイルをダウンロードする
4. Ankiに読み込む

そこで，撮影した単語帳の写真をアプリで読み込み，OCRで単語カードの候補を作れるようにしました．生成AIにファイルを作らせる手順が不要になり，単語カードの作成に使っていた時間と労力を，学習そのものに充てられます．

## 2. こだわった点・苦労した点

- **OCRの読み取り精度**：単語帳の写真をそのまま読み取ると，背景の色や模様に邪魔されて誤認識が多くなりました．英単語と訳の範囲を切り出し，黒い文字・赤い文字だけを残すように画像を変換してから読み取ることで，精度を上げました．
- **保存時のエラーへの対策**：通信が途中で切れた場合や，同じカードを2回保存しようとした場合でも，カードが二重に登録されないようにしました．エラーの種類ごとに原因を調べ，「保存されたか分からない」「入力に誤りがある」などの状態に分けて，それぞれ画面で案内するようにしました．

## 3. 操作方法

1. トップページから「ログイン」（下のテスト用アカウント）または「新規登録」を行う
2. http://localhost/decks で単語帳（デッキ）を作成し，名前をクリックして詳細画面を開く
3. 「画像から読み取る」を押し，サンプル画像（`docs/images/sample-card.png`）を選んで「読み取り開始」
4. 候補欄の英語・訳を元画像と見比べて修正し，チェックを入れて「選択した候補を保存」
5. デッキ詳細でカードが追加されていることを確認する
6. 「Anki用ファイルをダウンロード」を押し，Ankiに取り込む（設定は [docs/anki-setup.md](docs/anki-setup.md)）

## 5. 補足

**起動手順**

```bash
cd eitango-app
docker run --rm -u "$(id -u):$(id -g)" -v "$(pwd):/var/www/html" -w /var/www/html \
  laravelsail/php84-composer:latest composer install --ignore-platform-reqs
cp .env.example .env
./vendor/bin/sail up -d
# MySQLの起動に数十秒かかるため，少し待ってから次を実行する
./vendor/bin/sail artisan key:generate
./vendor/bin/sail artisan migrate --seed
./vendor/bin/sail npm install && ./vendor/bin/sail npm run build
```

**対応する画像**：1単語分を切り出し，上部に黒い英単語，下部に赤い訳がある画像（例：`docs/images/`）．読み取り結果には誤りが含まれるので，修正してから保存してください．

**未対応**：見開きページ・複数単語の読み取り，黒い文字の訳，アプリ内での学習機能

**今後の拡張予定（今回の提出版には未実装）**

- スマートフォンのカメラで撮影し，写真をアルバムやサーバーに保存せずにOCRへ渡す機能．将来的には連続映像からの自動読み取りも検討する
- 画像上で読み取り範囲を指定して複数カードを作成する機能．さらに，ページ・見開き全体から英単語と訳を対応づける処理へ広げる
- AnkiConnectを利用してPCのAnkiへ直接追加・更新し，ファイルのダウンロード・手動取り込みを省く機能．スマートフォンへの同期はAnkiの標準機能を利用する
- 例文・類義語・Tipsなどを保存できるカード詳細や，アプリ内の学習・復習機能
