# Ankiの設定

## ノートタイプの作成（初回のみ）

1. Ankiで「ツール → ノートタイプを管理 → 追加」を選び，「追加：基本（裏表反転カード付き）」を選んで名前を `eitango` にする
2. 「フィールド」で，次の順番になるように名前を変更・追加する

| 順番 | フィールド名 | 内容 |
| --- | --- | --- |
| 1 | ExportID | カードごとの固定ID（Ankiが同じカードか判定するために使う） |
| 2 | Front | 英単語 |
| 3 | Back | 日本語訳 |

3. 「カード」で，テンプレートを次のように設定する

| | 表面 | 裏面 |
| --- | --- | --- |
| カード1（英語→訳） | `{{Front}}` | `{{FrontSide}}<hr id=answer>{{Back}}` |
| カード2（訳→英語） | `{{Back}}` | `{{FrontSide}}<hr id=answer>{{Front}}` |

## 取り込み

1. アプリのデッキ詳細で「Anki用ファイルをダウンロード」を押す
2. Ankiで「ファイル → 読み込む」を選び，ダウンロードしたファイルを開く
3. 次のように設定して読み込む

| 項目 | 設定 |
| --- | --- |
| ノートタイプ | eitango |
| デッキ | 取り込み先のデッキ |
| 既存のノート | 更新 |
| 一致の範囲 | ノートタイプ |
| フィールドの対応 | ExportID ← 列1，Front ← 列2，Back ← 列3，タグ ← なし |

アプリでカードを編集したあと，再度ダウンロードして同じ設定で読み込むと，カードは増えずに内容が更新されます．
